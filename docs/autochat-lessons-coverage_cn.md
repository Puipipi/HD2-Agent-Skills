# AutoChat 经验：覆盖范围与证据

[English](https://github.com/Puipipi/HD2-Agent-Skills/blob/main/docs/autochat-lessons-coverage.md) / 简体中文

这是从 AutoChat 工作中整理出的可复用经验索引，不是产品变更日志，也不代表每种行为都经过实机测试。下文产品链接固定到不可变提交 [`4445596a76ed387edc3c09d0d25aa9d06ffd5b11`](https://github.com/Puipipi/HD2-AutoChat/tree/4445596a76ed387edc3c09d0d25aa9d06ffd5b11)。操作方法见相应 skill；本页说明 AutoChat 证据能证明什么、不能证明什么。

置信度标签：**离线**表示在 LuaJIT/假引擎边界上运行过测试；**源码/build 固定观察**表示检查了该版本的代码或原生谓词；**定点实机采样**表示只观察过一个特定目标。它们都不代表已覆盖其他游戏 build。

## B. 事件聊天、模板、预设与插件

| B1 | 核心事件冷却默认按触发玩家共享；显式规则冷却改用该玩家+规则的独立桶，而不是叠加默认桶。被冷却拒绝的事件会消费/丢弃，不留待稍后发送；已经入队但暂时发送失败的消息仍保留原有有界重试。零冷却核心规则走 urgent 路径，但仍受正常守卫约束。 | [事件聊天自动化](../skills/hd2-event-chat-automation/SKILL_cn.md)；[冷却实现](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/src/chat_automation.lua)、[冷却测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_chat_automation.py)。 | 离线策略/队列测试及固定源码。 |
| B2 | 欢迎消息按每位新人独立计时；定时消息到期时不受事件冷却阻挡。两者都不写入或延长事件冷却 ledger。各自 delay/周期、session、角色、启用、solo/output、原生发送检查仍生效。 | [事件聊天自动化](../skills/hd2-event-chat-automation/SKILL_cn.md)；[欢迎/调度测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_chat_automation.py)、[定时任务测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_scheduled_tasks.py)。 | 离线计时/策略测试；不声称实机多人时序已验证。 |

| B5 | 核心会把已知完整玩家名包在方括号中，并仅在发送者颜色选项启用时着色；插件消息也会加方括号但不会自动染名。身份缺失时不伪造括号。 | [玩家模板指南](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/docs/PLAYER-TEMPLATES.md)；[格式化/输出测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_chat_automation.py)。 | 离线格式化测试；最终表现受输出配置影响。 |
| B6 | 消息正文前加一个 LF；511 字节正文预算包含颜色标记，LF 加正文必须在 512 字节聊天限制内。按 UTF-8 边界截断，并在预算内闭合活动颜色标记。 | [玩家模板指南](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/docs/PLAYER-TEMPLATES.md)；[字节预算测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_chat_automation.py)。 | 离线字节级格式化测试；不代表所有外部聊天传输。 |
| B7 | 内置预设是中英×角色的四个种子，不能删除、覆盖或改名。它们开启实际提醒开关，同时保留角色输出/solo 策略，并非“所有布尔值都开”。新安装默认选英文内置项与 UI 语言无关；只有手动应用才改变活动设置。不会迁移现有用户配置或自定义预设。 | [插件 API/预设文档](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/docs/PLUGIN-API.md)；[预设库测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_preset_library.py)、[配置测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_auto_chat_probe.py)。 | 离线预设/配置测试和源码。 |
| B8 | 插件 API 是独立契约：`cooldown=0` 不会去重重复 `send`，调用方须自行去重回调；插件发送不继承核心队列/seen 语义。独立策略仍保留消息合法性/session/角色/原生发送检查。预设 hooks 需显式选择，保留未知 blob，应用前预检并支持回滚。只读快照包含角色选项、可移植任务定义（名称/模式/时间/消息/启用状态，不含运行时 ID/due/结果/进度）和选择加入的插件 blob；旧快照没有任务字段时保留目标角色现有任务。没有普通条目数上限，但受 payload（1 MiB）、持久化（16 MiB）和安全序号范围限制。 | [插件 API](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/docs/PLUGIN-API.md)；[插件测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_plugin_integration.py)、[快照测试](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/tests/test_preset_library.py)。 | 离线契约测试；插件调用方需自行处理重复回调。 |

## 性能证据与限制

离线 benchmark 方法见 [PERFORMANCE-OFFLINE-1.0.0.md](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/docs/PERFORMANCE-OFFLINE-1.0.0.md) 和 [`bench_frame_performance.py`](https://github.com/Puipipi/HD2-AutoChat/blob/4445596a76ed387edc3c09d0d25aa9d06ffd5b11/work/standalone/bench_frame_performance.py)。对 1,000 条角色匹配、启用、未完成且 deadline 在未来的任务，离线 mean 从 0.02250 ms 降到 0.00428 ms，周期 poll mean 从 0.60509 ms 降到 0.07849 ms。这是 LuaJIT/假引擎对照，不保证真实游戏每帧 0.05 ms。benchmark 在 Lua 内用 QPC 计时、使用全新 runtime 和预热、固定源码引用、Lua table 样本和只计数的 GUI stub；稳态与周期 poll 分开报告。减少 wrapped-text 调用次数没有带来稳定测时收益，因此撤回。默认短提示重绘不代表长 CJK/英文文本或大量规则；应使用确认真实重绘的代表性 fixture，并把布局正确性测试与计时分开。

## 复现与源码边界

链接的产品源码和测试是该固定版本的不可变证据，不是实机部署检查。将修复用于其他环境前，核对管理器实际 payload/resource 哈希及独立 patch build 标识；产品版本可在多个 patch build 间保持 `1.0.0`。AutoChat 文档中的游戏内 IME 验收仍未完成。此处没有证明所有事件 producer 均覆盖、所有分辨率原生渲染正常，或实机舰桥到任务场景的 GUI 拆除成功。
